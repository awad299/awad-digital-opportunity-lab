# Awad Digital Opportunity Lab

Arabic-first capability showcase for commercial opportunities that recur in the Gulf market.

## Positioning
This site does **not** present opportunity posts as completed client work. It publishes independent capability demos inspired by repeated market demand and lets prospects request a tailored implementation.

## Current live demo
- MasarFlow — Arabic Sales Funnel Builder: https://masarflow-arabic.netlify.app

## Local
```bash
npm install
npm run dev
npm run build
npm run test:e2e
```

The contact form is prepared for Netlify Forms and is detected during deployment.
